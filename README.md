# ADAUGO-UCHE-DecodeLabs--Internship.
EDA's goal is to analyze a dataset to understand patterns, trends, and distributions.
The Quantity, UnitPrice, and TotalPrice columns were analyzed using count, mean, and median statistics. TotalPrice showed a noticeable difference between the mean and median, indicating a positively skewed distribution. This suggests the presence of extreme high-value purchases that increase the average transaction value. Since the median is less sensitive to outliers, it provides a more reliable representation of the typical customer purchase amount.
